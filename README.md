# Beauty Salon Platform

A salon point-of-sale app built for everyday front-desk work. Staff can take bills, review daily reports, and manage the salon without a complicated setup.

## Features

- **Billing** — Create bills for services quickly at the counter.
- **Reports** — Review sales and daily reports so the day is easy to close and check.
- **Staff** — Add and manage staff from the admin area.
- **Services** — Add and maintain the services offered in the salon.
- **Roles and permissions** — Control what each person can see and do, so front desk and admin stay separate.
- **Simple to operate** — Screens and flows are meant for daily use, so new staff can learn them quickly.
